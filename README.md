# ANSWER RAID · 计算机协会百团大战答题终端

一个中英双语的**三档难度答题网站**。技术栈：**Svelte 5 + Vite + TypeScript**。
仅提供排位赛；共享排行榜与排位赛使用 **Vercel Functions + Neon Postgres**。
部署、数据库初始化和验证方法见 [共享排行榜](docs/leaderboard.md)。

```bash
pnpm install
pnpm dev        # 开发预览 http://localhost:5173
pnpm build      # 产物在 dist/
pnpm preview    # 本地起静态服务预览 dist
pnpm test       # 全套验证(类型检查 + 题库 + 引擎 + 构建 + DOM 冒烟)
pnpm db:migrate # 配置 .env.local 中的 DATABASE_URL 后，初始化排行榜表
```

## 玩法:三档递进,越往上越不许犯错

一局 = **三档 × 每档 6 题**(共 18 题),答满一档晋级下一档,通关 IN 档才算封神。

档位代号沿用音游的难度分级习惯,只是**难度标识**:

| 档 | 名称 | 内容 | 限时 | 不灭次数 | 基础分 |
|---|---|---|---|---|---|
| 01 | **EZ** 轻松 | 计算机常识 · 读题就能答 | 40s | 2 | 100 |
| 02 | **HD** 进阶 | 基础概念 · 别信直觉 | 35s | 2 | 200 |
| 03 | **IN** 深入 | 专业名词与底层语义 · 答错即出局 | 30s | 1 | 320 |

面向**有高中数学知识的大一新生**:EZ/HD 读题就能做,之后逐档加码。
全部为选择题,**不需要纸笔、现场能快速作答**。
界面**中英双语**、**明暗双主题**,右上角各有开关;答题中可点击 **退出本局**。

- **不灭次数**:该档内允许答错的次数,**归零立即出局**;晋级时按新档位重置
  → **IN 档错一题就出局**。
- **连击**:每答对一题连击 +1,**跨档累积**,倍率 `1 + 0.1×(连击-1)` 封顶 **×2.0**;
  答错或超时清零。
- **时间奖励**:`1 + 0.5 × 剩余时间占比`,答得越快乘得越高。
- **超时**:倒计时归零即判定为答错,与选错同等处理并展示原理。
- **中途退出**:点击「退出本局」弹确认框，倒计时仍继续；确认后丢弃本局，不进入排行榜。

每题得分:

```
得分 = 基础分 × 时间系数(1.0 ~ 1.5) × 连击倍率(1.0 ~ 2.0) × 情报折扣(1.0 / 0.4)   (一局满分 10185)
```

### 三个锦囊(整局限用 3 次,不补)

| 按钮 | 锦囊 | 效果 |
|---|---|---|
| 50:50 | ⧗ 逻辑切割 | 抹除两个错误选项(正确项永不被抹除) |
| +15s | ❄ 时间冻结 | 当前题目回补 15 秒(不超过本题上限) |
| 提示 | ◈ 内线情报 | 提示考点标签,本题得分 **×0.4** |

## 题库

当前题库共 **118 题**，每题都有中文与英文题干、选项及讲解。
保留原有 39 题，新增文档中缺失的 79 题；原文 103 题均有唯一的 `sourceRef` 对应。
来源、答案纠错和验证方法见 [题库审核记录](docs/question-bank-review.md)。
题目分档由 `src/lib/data/questions/` 中每题的 `tier` 字段决定；
页面题量、自检档位和每档所需正确题数直接从数据与配置推导。

每档需**答对 6 题**晋级，错题扣命且不计入晋级进度，所以一局实际作答可能超过 18 题。

## 每局都不一样

- **随机抽题**:每局从题库里抽**本局未出现过**的题;某档抽尽后重新洗牌(避开最近一题)。
- **选项打乱**:每次抽题都会重新打乱 4 个选项的顺序,正确项位置随机 —— 背「选 B」没用。
- 两个机制都在测试里做了统计验证(见下)。

## 排位赛与排行榜

- `#/ranked`：服务器抽题、判分、计时并保存完成的成绩；排行榜不接受客户端直接上传分数。
- `#/leaderboard`：前 50 名，支持今日 / 全部、10 秒自动刷新、全屏展示。中英文界面均可使用。
- 首页仅提供排位赛和排行榜入口，不再展示本地练习或本地档案。
- 排位赛不会暂停，切换页面或打开退出确认时仍会计时。刷新后可恢复同一浏览器标签页内的未过期排位赛。
- 排位赛使用 A/B/C/D 作答、按钮使用锦囊；判定后点击下一题继续。倒计时无法暂停。

这是休闲活动排行榜：服务器校验可阻止伪造得分和重复计分，但题库源码公开，不能阻止查答案或脚本答题。
游客编号保存在浏览器 cookie 中，不是实名账户，也不会跨设备同步。

## 主题:暗色 CRT / 亮色强光

右上角按钮一键切换(`☀` 表示点了变亮色,`☾` 表示点了变暗色)。

| 主题 | 用途 | 视觉 |
|---|---|---|
| **暗色**(默认) | 室内、晚上 | 原版 CRT:扫描线 + 暗角 + 字符雨 + 辉光 |
| **亮色** | **强光环境**(户外摊位、正午阳光下的屏幕) | 白底高对比;关掉扫描线 / 暗角 / 字符雨 |

亮色不是把暗色反转,做了三件必要的调整:

1. **强调色降亮度提饱和** —— 暗色下用 `hsl(hue 100% 62%)`,放到白底上会糊;亮色改用 `hsl(hue 88% 30%)`;
2. **面板改为不透明** —— 暗色下 `backdrop-filter` + 半透明底色很好看,但亮色下背景会透上来吃掉对比度;
3. **新增 `--on-accent` 令牌** —— 强调色/危险色实心块上的文字,暗色下是近黑、亮色下反过来要用白。

实现要点:

- 两套取值都写在 `src/app.css`,用 `[data-theme='light']` 覆盖 `:root` 的**同一套语义令牌**;
  `tools/theme-test.mjs` 会校验两套令牌**一一对应**(漏一个就会亮色下漏出暗色的值)。
- `--hue` 仍然由 JS 按档位写入,所以三个档位的换色在亮色下照样生效。
- 主题状态在 `src/lib/theme.svelte.ts`(runes 单例),优先级 `?theme=` > localStorage > 系统偏好 > 暗色。
- `index.html` 里有**一段内联脚本在首帧前**就把 `data-theme` 写上 —— 否则亮色用户每次加载
  都会先闪一下暗色。
- 组件里已不存在硬编码的暗色(`#04060a` / `#eafff6` 等),全部走令牌;`theme-test.mjs` 会拦住漏改。

## 中英双语(i18n)

语言开关在**右上角常驻按钮**「🌐 EN」(中文界面)/「🌐 中」(英文界面)——
按钮上显示的是**点了会切过去的**语言,所以对局中途也能随时切换。

- **语言优先级**:`?lang=` 查询参数 > localStorage > 浏览器语言 > 默认中文。
  查询参数这条路是给自动化测试与分享链接用的,例如 `index.html?lang=en` 直接以英文开局。
- **界面文案**:全部集中在 `src/lib/i18n.svelte.ts` 的字典里,组件用 `msg()` / `fmt()` 取。
  带插值的句子写成 `Msg((p) => ...)`,渲染时再求值,所以切语言时连「剩余不灭 1」这类
  动态文案也会立刻跟着变。字典的 zh / en 两组 key 由 `pnpm test:bank` 校验必须一一对应。
- **题库**:不走字典。每题自带 `zh` / `en` 两份文本(`prompt` / `options` / `explain`)。
  - **切语言时连"当前这道题"都会立刻变**:引擎只保存**双语源码 + 选项顺序**,
    题干/选项通过 `currentQuestion()` **按当前语言即时摊平** —— 所以不需要等下一题。
    (早期版本在抽题时就把文本冻结成单语,切语言只换界面、题目本身不变,这个 bug 真踩过。)
  - 选项顺序与语言无关,一次打乱两种语言共用,因此切语言**不会打乱选项、也不会丢失
    "已用逻辑切割抹掉的两个选项"**。
  - **`answer` 下标两种语言共享** —— 改选项时两边必须同步增删,否则 `pnpm test:bank` 会报错。
- **题目标签**:`tags` 是写死在题目里的中文键(如 `补码`),展示时走字典的 `tag.*` 命名空间
  (`tagLabel()`)。
  - 漏译时回退成 key 本身,**刻意不加 `!` 之类的标记** —— `Python` / `Transformer` / `Web` /
    `GPT` / `NP` 这些标签的正确中英形式本来就一样,靠"值等不等于 key"来判断会把它们
    污名化成 `Python!`(这个坑真踩过)。
  - "有没有真的翻译"由 `pnpm test:bank` 比对 **zh 与 en 两份取值**:中文改了说法而英文
    还等于中文值(典型的复制粘贴漏改)会直接报错;两语相同的专有名词则放行。
- **回归防线**:`pnpm test:store` 会**逐题核对整个题库** —— 每道题在 zh / en 下各抽一遍,
  断言题干、讲解、选项数都随语言变化,且英文文本里不含汉字、标签也能正确渲染。
- **加一种语言**:在 `LOCALES` 里加代码、补一份字典(含 `tag.*`)、给题库每题补一份文本即可;
  `tools/ts-resolve.mjs` 已经能处理带 runes 的 `.ts`,新语言不需要碰构建配置。

### 视觉与音效

- **配色由档位色相驱动**:引擎把当前档位的 `--hue` 写进 `:root`,EZ 152(绿)、
  HD 190(青)、IN 268(紫)、AT 38(琥珀)、SP 320(品红),晋级时整站配色**平滑切换**。
- 全站等宽字体 + CRT 扫描线 + 暗角 + 噪点 + 字符雨 + 标题 glitch 重影(亮色主题下全部关闭)。
- 音效**全部现场合成**(方波/三角波/锯齿波 + 带通噪声):悬停、作答、正误、晋级、
  结算、超时 glitch,外加一层 55/110/165 Hz 的缓慢「呼吸」底噪。右上角可静音,偏好会记住。
  - 底噪的 55 Hz 在笔记本/手机外放上基本发不出来,所以额外叠了 110/165 Hz 的中频层,
    否则听起来就像没声音。
  - **AudioContext 必须等用户手势再创建**:在 `onMount` 里就 `new AudioContext()` 会被
    浏览器自动播放策略挂起,底噪节点建好也一声不响。现在改由一次性手势监听解锁,
    且每次取用都会确认 `resume()`(`pnpm test:dom` 里有探针守着这两条)。
  - **静音开关的状态用 runes 镜像了一份**:`audio.ts` 是普通模块,模板直接读它的变量时
    Svelte 追踪不到 —— 点了按钮状态变了、图标却不重绘,看起来就像「按钮点不动」。
- 尊重 `prefers-reduced-motion`。

## 改造成你们社团的版本

1. **换题目**:改 `src/lib/data/questions/*.ts`,每题结构见 `src/lib/data/types.ts`。
   加题后同步把 `ROUNDS_PER_TIER`(`src/lib/data/types.ts`)按需调整。
   `explain` 会直接展示给参赛者,建议写清「为什么对 + 最诱人的错项错在哪」。
2. **换二维码**:`public/QR.png` 就是结算页「加入我们」里那张招新群二维码,
   直接换掉这个文件即可(组件里已写成 `src="./QR.png"`,用的是相对路径)。
3. **换配色**:改 `src/lib/data/tiers.ts` 里各档的 `hue` 即可,全站跟着变。
4. **调难度**:同一文件里的 `allowMiss` / `timeLimit` / `baseScore`。

## 部署

完整游戏部署到 **Vercel**，并配置 Neon 的 `DATABASE_URL`。静态服务仅能预览页面，无法运行排位赛或共享排行榜 API。

`.github/workflows/deploy-pages.yml` 在推送到 `main` 时运行检查、构建与 DOM 测试。GitHub Pages 发布仅通过手动 `workflow_dispatch` 触发，用于静态页面预览。

`test:ci` 是 `pnpm test` 去掉构建与 DOM 冒烟的那一半(类型检查 + 题库 + 答案用例 +
主题 + 回归 + 商店引擎),给 CI 和本地快速自检用;`test:dom` 需要 `dist/` 产物,
所以排在校验之后单独跑。

工作流里 pnpm 版本是**写在工作流里**的(`pnpm/action-setup` 的 `version: 12.4.2`)。
刻意不在 `package.json` 里加 `packageManager` 字段:那会让 pnpm 把**它自己**写进
lockfile 的 `packageManagerDependencies`,与 CI 的 `--frozen-lockfile` 冲突
(`ERR_PNPM_FROZEN_LOCKFILE_WITH_OUTDATED_LOCKFILE`)。升级 pnpm 时改这一处即可。

启用前提(已设置,换仓库时需要重做):仓库 Settings → Pages → Source 选
**GitHub Actions**。`dist/` 在 `.gitignore` 里,所以走的是 artifact 发布而不是分支发布;
工作流会额外写一个 `dist/.nojekyll` 关掉 Jekyll 处理。

其他托管方式同理:内网 nginx 只需把 `dist/` 放到任意子路径,不需要改构建配置。

## 引擎回归验证

`pnpm test:regression` 使用确定性时钟检查真实引擎：满分 10185、连续答对计分与明细一致、
有失误通关为 SS、零失误通关为 SSS，以及退出确认期间答题和反馈计时均暂停。
取消退出后继续剩余展示时间；确认退出后清理所有待执行的推进任务。
`pnpm test:store` 显式设置初始语言，不受运行机器的语言偏好影响。
